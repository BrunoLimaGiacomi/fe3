# GRC Frameworks Compliance

## Escopo

Use esta skill quando o pedido envolver frameworks, normas, requisitos, conformidade, auditoria, PCI, SGSI, BCMS, gestão de riscos ou mapeamento entre controles.

## Diretrizes

- Confirme framework, versão, escopo, período, unidade/processo/sistema e critério de avaliação antes de concluir.
- Para afirmações atuais ou formais, valide a versão em fonte oficial. Referências operacionais: ISO/IEC 27001:2022, ISO 22301:2019, ISO 31000:2018 e PCI DSS v4.0.1.
- Não trate requisitos de frameworks diferentes como equivalentes por padrão. Explique se o mapeamento é direto, parcial, contextual ou não aplicável.
- Separe requisito, objetivo do controle, controle implementado, evidência, teste, lacuna e risco residual.
- Não declare conformidade, certificação ou atendimento PCI sem evidência suficiente, escopo definido e critério aceito.
- Para ISO/IEC 27001, considere contexto, liderança, planejamento, suporte, operação, avaliação de desempenho, melhoria, riscos de SGSI, controles do Anexo A e Declaração de Aplicabilidade.
- Para ISO 22301, considere BCMS, BIA, requisitos de continuidade, estratégias, planos, exercícios e melhoria.
- Para ISO 31000, use contexto, identificação, análise, avaliação, tratamento, comunicação, consulta, monitoramento e revisão de riscos.
- Para PCI DSS, delimite CDE, fluxos de dados de pagamento, armazenar/processar/transmitir, responsabilidades, validação aplicável, requisitos, evidências e abordagens compensatória/customizada quando cabíveis.

## Entrega

Priorize uma matriz com: framework, requisito, controle, evidência esperada, evidência disponível, lacuna, risco, owner, prazo, status e decisão necessária.
